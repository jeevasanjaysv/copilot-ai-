# Copilot AI

Small application prototypes and design samples.

## Weather dashboard

Open `weather.html` in a browser. For local testing, serve the repository directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000/weather.html`. The page provides city search, current conditions, hourly and 7-day forecasts, and Celsius/Fahrenheit controls. Forecast data comes from Open-Meteo; **View Google Weather** opens Google's forecast search for the selected city.

The browser test recording is in `artifacts/weather-test.webm`.
